# unit-testing

A small JavaScript (Node.js) library with basic math functions and unit tests.
Made for the DevOps Engineering (Software Testing) course at LAB University of Applied Sciences.

## Functions

| Function | Description |
|---|---|
| `add(a, b)` | Returns a + b |
| `subtract(a, b)` | Returns a - b |
| `multiply(a, b)` | Returns a * b |
| `divide(a, b)` | Returns a / b, throws an error if b is 0 |

## Requirements

- Node.js and npm

## Installation

```
git clone https://github.com/Cristi192005/unit-testing.git
cd unit-testing
npm install
```

## Running the tests

```
npm test
```

The tests are written with Mocha and Chai and are located in the `tests` folder.
